UNPACKED EMPIRES

Privacy Policy

Last updated: November 18, 2026

This policy explains how “Unpacked Empires Uploader” (the “App”) handles data. The App is a private tool used only by the owner of the Unpacked Empires YouTube channel.

Data the App accesses

With the channel owner’s permission, given through Google’s sign-in screen, the App uses the YouTube Data API to upload videos and set video details (title, description, tags, thumbnail) on the owner’s own channel, and to read public YouTube statistics for topic research.

How data is used

Data is used only to publish and manage the channel’s own videos. The App does not collect data from viewers or any other users.

Storage and security

The access token from Google is stored as an encrypted secret in the channel owner’s private GitHub account and is used only by the owner’s automation. It is never sold, shared, or transferred to anyone.

Google API Services

The App’s use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The App uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the contact details on the Unpacked Empires channel page.
